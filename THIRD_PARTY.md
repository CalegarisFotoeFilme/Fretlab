# Terceiros

O FretLab é um projeto pessoal, sem fins comerciais. Se um dia ele virar produto, revisar esta lista é o primeiro passo.

| Componente | Uso | Licença |
|---|---|---|
| [alphaTab](https://alphatab.net) (`@coderline/alphatab`) | renderizar/tocar Guitar Pro e MusicXML, exportar o MIDI convertido | MPL-2.0 |
| Fonte **Bravura** (SMuFL, distribuída com o alphaTab) | glifos de notação (alphaTab e pauta rítmica) | SIL OFL 1.1 |
| Soundfont **Sonivox** (distribuído com o alphaTab) | timbres do player | Apache-2.0 |
| [pitchy](https://github.com/ianprime0509/pitchy) | detecção de altura (McLeod Pitch Method) | MIT |
| [@tonejs/midi](https://github.com/Tonejs/Midi) | leitura de arquivos MIDI | MIT |
| [Dexie](https://dexie.org) | IndexedDB | Apache-2.0 |
| React, React Router, Zustand, Motion | interface | MIT |
| [Lucide](https://lucide.dev) | ícones | ISC |
| Tailwind CSS, Vite, vite-plugin-pwa | build e estilo | MIT |
| Google Fonts: Big Shoulders Display, Atkinson Hyperlegible Next/Mono | tipografia | SIL OFL 1.1 |

## Conteúdo de terceiros

- **Songsterr**: o app não embute nem baixa nada do Songsterr. Ele só abre o site numa janela e importa os arquivos que você baixou com a sua assinatura. As tablaturas importadas ficam só no seu navegador e não vão para o repositório.
- **Livros citados em `docs/METODOLOGIA.md`**: usados como referência de abordagem. Nenhum texto foi reproduzido.
